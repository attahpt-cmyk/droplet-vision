# Droplet Vision Computer vision pipeline for automated droplet detection and measurement from high-speed imaging data
Droplet Vision is an ongoing research and development project focused on developing a computer vision pipeline for the automated detection, segmentation, tracking, and measurement of droplets from high-speed imaging data.

The project aims to develop a reliable and scalable approach for extracting quantitative information from high-speed recordings of liquid jet breakup and droplet formation.

Project Goals
Automated detection of droplets and fragmented liquid structures
Image preprocessing and segmentation
Measurement of droplet size and shape
Estimation of droplet position and velocity
Analysis of droplet formation and breakup over time
Processing of large high-speed imaging datasets
Development and evaluation of machine-learning/deep-learning approaches for robust droplet detection
Planned Approach

The pipeline is being developed progressively, starting with classical computer vision techniques such as image preprocessing, thresholding, edge detection, morphological operations, and connected-component analysis.

Machine-learning and deep-learning methods will subsequently be investigated to improve the detection and segmentation of small, overlapping, blurred, or partially fragmented droplets.

Research Context

The project is motivated by experimental investigations of liquid jet breakup and droplet formation in a gaseous environment. The extracted droplet characteristics will be used for quantitative analysis of breakup dynamics and spray behavior.

Current Status

🚧 In development

The current work focuses on establishing the image-processing pipeline, evaluating detection performance on high-speed imaging data, and developing a robust approach that can be extended to automated analysis of experimental datasets.
